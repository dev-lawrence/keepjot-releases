# KeepJot releases

Official downloads for KeepJot, a desktop app for capturing tasks and reference notes.

KeepJot was previously named Jot. The existing v1.1.0 beta and its installer filenames retain the old name because those binaries were built before the rebrand. New KeepJot installers will be published as a new release once the Mac and Windows builds are ready.

Current beta builds are unsigned; the Mac build is also not notarized.
